Лаборатория инструментов

Локальные модели создают инструменты обработки данных, проверяют их на эталонных примерах и запоминают опыт. Принимаются версии, прошедшие все тесты; улучшение версии измеряется сокращением числа операций.

Подключение…
Цикл работает при закрытой вкладке, пока включён компьютер.

Модели и роли

Автор выбирается по результатам предыдущих попыток среди отмеченных моделей. Проверяющий может быть другой моделью. GPU используется по очереди совместно с обычным чатом. Большие модели переключаются медленнее.

Новая задача

Опиши обработку текста или JSON и задай правильные ответы. Тесты задаёшь ты — модель не может их переписать. Первая половина примеров видна модели, остальные используются при проверке.

Память и результаты моделей
Это развитие инструментов и памяти, без переобучения весов. Инструменты состоят из ограниченного набора операций; произвольные программы, команды Windows и интернет здесь не исполняются. После обработки задач цикл ждёт новые и проверяет сохранённые версии. После трёх ошибок подряд останавливается.
