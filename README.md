## Возможности

| | Что доступно |
|---|---|
| **Потоковые ответы** | Текст появляется по мере генерации. Ответ можно остановить в любой момент. |
| **Библиотека моделей** | Загрузка по ссылкам Hugging Face и Ollama, очередь и продолжение загрузок. |
| **История диалогов** | Отдельные чаты, автоматическое сохранение сообщений и частичных ответов. |
| **Управление контекстом** | Подсчёт токенов, индикатор заполнения и сводки ранних сообщений. |
| **Свои инструкции** | Отдельный системный промпт для каждой модели. |
| **Доступ с телефона** | Общие диалоги через браузер в локальной сети. |

Вычисления выполняются локально через **llama.cpp с CUDA**. Ollama используется для работы с её библиотекой моделей. Открытие страницы само по себе не загружает модель на видеокарту.

## Запуск

Потребуются Windows, NVIDIA GPU с поддержкой CUDA, Node.js 22+ и Ollama. Совместимую Windows CUDA-сборку llama.cpp — `llama-server.exe` и её библиотеки — нужно подготовить в `runtime/`. Веса и движок не входят в репозиторий.

```powershell
git clone https://github.com/safromaks-cell/simple-chat.git
cd simple-chat
```

Если Ollama ещё не работает, запусти её:

```powershell
ollama serve
```

В другом терминале запусти чат:

```powershell
node run-chat.cjs --web-only
```

Открой **[localhost:8791](http://127.0.0.1:8791)**.

1. Вставь ссылку на модель и дождись загрузки.
2. Выбери её в списке и нажми **«Загрузить на GPU»**.
3. При необходимости задай системный промпт.
4. Начни диалог. **Enter** отправляет сообщение, **Shift + Enter** добавляет строку.

В исходной настроенной установке доступен `Start Chat.cmd`. Лаунчер использует дополнительный путь Node из окружения Codex; на другом компьютере используй команду выше.

## Модели и контекст

Поддерживаются репозитории Hugging Face с GGUF, ссылки на конкретные файлы и модели Ollama. Разделённые GGUF также поддерживаются. Совместимость архитектуры определяется сборкой llama.cpp.

При смене модели предыдущий процесс выгружается. Все слои настраиваются на CUDA; автоматического переключения вычислений на CPU нет. Профили контекста находятся в `context-profiles.json`. При нехватке памяти контекст может уменьшаться.

Полная переписка сохраняется на диске. Для текущего запроса ранние сообщения при необходимости сжимаются в сводку. Сжатие требует отдельной генерации и может опустить детали; состояние контекста отображается в интерфейсе.

## Локальная сеть

На другом устройстве открой `http://<IP-компьютера>:8791`. Актуальные адреса показаны в **«Доступ в сети»**. При необходимости `Enable Network.cmd` добавляет правило Windows Firewall для локальной подсети.

У устройств общие диалоги и настройки. В текущей конфигурации доступ по локальной сети работает **без пароля**.

## Данные

| Каталог | Содержимое |
|---|---|
| `data/` | Диалоги, настройки и сводки контекста |
| `models/` | Скачанные модели |
| `runtime/` | llama.cpp и его библиотеки |
| `credentials/` | HF-токен, защищённый Windows DPAPI |

Эти каталоги исключены из Git. HF-токен используется для запросов к Hugging Face и не передаётся веб-интерфейсу.
